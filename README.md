# AI 통제 운영평가 시스템

금융회사 내부통제 담당자가 정기 운영평가 표본의 증빙을 확인하고, 통제 기준에 따라 결과를 검토·확정한 뒤 운영평가 조서 초안을 생성하는 업무 화면입니다.

대표 통제는 **1,000만 원 이상의 비용 지급 건에 대해 지급 전에 부서장과 재무담당 임원의 승인을 받아야 한다**는 고액 비용 사전 승인 통제입니다.

## 구현 기능

- 6개 평가 표본의 조회, 검색 및 상태별 필터
- 지급 전표와 전자결재 승인 문서 미리보기
- 증빙 분석 진행 단계 및 사전 정의된 평가 항목 추출
- 추출 항목과 원본 문서 위치 간 하이라이트 연결
- 증빙 미제출, 승인 기록 부재 및 추출 불확실성 검토
- 통제 기준에 따른 결정론적 PASS, FAIL, REVIEW, N/A 판정
- 원본 확인을 통한 불확실한 승인일 수동 보정
- 평가자 의견, 후속조치 및 중요도 저장
- 증빙 보완 및 재검토 요청 이력 관리
- 평가 결과 확정, 재개 및 변경 사유 기록
- 평가 결과별 운영평가 조서 초안 생성과 인쇄
- 표본 목록 CSV 내보내기
- 실행 이력 및 상세 판정 근거 조회
- 브라우저 `localStorage`를 이용한 표본별 업무 상태 유지와 초기화

## 기술 스택

- HTML5
- CSS3
- Vanilla JavaScript
- 브라우저 Web API
  - `localStorage`
  - `Intl.NumberFormat`
  - `Intl.DateTimeFormat`
  - File API
  - Blob 및 CSV 다운로드
  - `window.print()`

외부 프레임워크, CDN, 외부 API 및 별도 서버를 사용하지 않습니다. 모든 화면, 데이터와 업무 로직이 단일 [`index.html`](./index.html) 파일에 포함되어 있습니다.

## 주요 업무 시나리오

### 1. 사후 승인에 따른 통제 미충족

`EXP-24002`의 증빙을 분석하면 재무담당 임원 승인일이 지급일 이후임을 확인합니다. 운영평가 실행 시 `통제 미충족`으로 판정되며, 개선권고 등 후속조치를 지정한 후 결과를 확정하고 조서 초안을 생성할 수 있습니다.

### 2. 자동 추출 불확실성의 담당자 확인

`EXP-24003`은 재무담당 임원 승인일을 자동으로 확인하지 못해 최초 `추가 검토 필요`로 표시됩니다. 담당자가 원본 문서에서 `2026.06.16`을 확인해 반영하면 재평가 결과가 `통제 충족`으로 변경되고 수정 이력이 보존됩니다.

### 3. 필수 증빙 미제출

`EXP-24005`는 전자결재 승인 문서가 제출되지 않아 자동 평가를 확정할 수 없습니다. 요청 대상, 보완 기한 및 사유를 입력하여 증빙 보완 요청을 등록할 수 있습니다.

### 4. 통제 적용 대상 제외

`EXP-24004`는 지급금액이 10,000,000원 미만이므로 승인 문서가 없더라도 증빙 부족이 아닌 `평가 대상 아님`으로 판정됩니다.

### 5. 필수 승인 기록 부재

`EXP-24006`은 재무담당 임원 승인 기록이 없어 `통제 미충족`으로 판정됩니다. 사후 승인 사례와 구분된 평가 의견 및 조서 문구가 생성됩니다.

## 실행 방법

Chrome에서 [`index.html`](./index.html)을 직접 열면 별도의 설치나 빌드 과정 없이 사용할 수 있습니다.
